# Web端 3D LUT\(Cube\)图片调色工具 完整技术方案文档

## 文档概述

本文档汇总全部技术论证、色彩科学原理、设备素材色彩规则、工具架构、双渲染管线、性能评估、正确性校验标准。
目标：实现**纯前端本地运行、无服务端、不上传图片**的 Cube 3D\-LUT 图片调色工具，支持 LUT 浓度调节，兼容 PS 效果、对齐达芬奇专业调色效果，适配相机、大疆设备实拍素材。

## 一、核心基础色彩科学原理

### 1\. sRGB 与 Rec\.709 核心异同

#### 相同点

- 色域范围完全一致

- 白点均为 D65

- 原色坐标无差异

#### 唯一核心差异

**伽马传递函数（TRC 曲线）不同**

1. Rec\.709：广播电视标准，分段曲线，专为**暗室观看电视、视频制作链路**设计

2. sRGB：互联网 / 显示器标准，分段曲线，专为**明亮室内电脑屏幕观看**设计

### 2\. 行业核心现状（历史底层原因）

1. 两套标准分属不同行业、不同年代：Rec\.709（广电 1990）、sRGB（互联网 1996）

2. 无统一的根本原因：观看环境、硬件生态、行业标准体系、海量存量素材兼容锁死

3. 视频行业默认 Rec\.709，图片行业默认 sRGB，生态割裂不可替代

### 3\. 跨空间套用 LUT 的核心问题

所有网络影视 Cube LUT，**均基于 Rec\.709 伽马制作**
直接给 sRGB 图片套用 Rec\.709 LUT：

- 色域无错误

- **灰阶、暗部、中间调会系统性偏移**（发灰、黑位异常、肤色偏移）

- 重风格 LUT 肉眼不易察觉，轻调色 LUT 偏差非常明显

## 二、实拍设备素材色彩空间统一规范（关键业务约定）

### 1\. 索尼相机

- 拍照模式直出 JPG：标准 **sRGB**

- RAW 格式：无色彩空间，后期导出时定义

### 2\. 大疆 Pocket 4P（普通 SDR 色彩，非 D\-Log2/HLG）

1. 视频录制 MP4：原生编码 **Rec\.709**（视频码流标准）

2. 机内视频截图 JPG：**机内自动转换为 sRGB**（重点：视频源≠图片文件空间）

3. Live Photo

    - 静态封面 JPG：sRGB

    - 内嵌短视频片段：Rec\.709

4. 拍照模式：JPG 为 sRGB、DNG RAW 无色彩空间

### 3\. 电脑播放器截图规则（QuickTime）

1. 系统截图（Cmd\+Shift\+4）：截取屏幕渲染画面，色彩为显示器空间（Mac Display\-P3）

2. QuickTime 复制帧 \+ 预览另存 JPG：**最终文件强制为 sRGB**

3. 结论：**所有普通用户产出的 JPG/PNG 图片，不存在原生 Rec\.709 图片文件**

### 4\. 工具全局输入工程约定（最终定稿）

1. 本工具**默认所有用户上传 JPG/PNG 均为 sRGB 编码**

2. 浏览器会自动归一化所有图片色彩空间，送入 WebGL 的像素流固定为 sRGB\-TRC

3. 无需解析、判断、兼容 Rec\.709 格式图片（民用场景不存在，浏览器不兼容）

## 三、工具整体架构设计

### 1\. 运行模式

- 纯前端静态网页，**无后端、所有计算本地浏览器完成**

- 图片、Cube 文件不上传服务器，隐私安全

- 可本地打开 HTML、GitHub Pages、NAS 静态站点部署

### 2\. 五大核心模块

1. 文件解析模块：解析本地图片、解析标准 `.cube` 3D\-LUT 文件

2. LUT 数据处理模块：提取 LUT 尺寸、元数据，构建 3D 查找数组

3. 渲染运算模块：三线性插值、色彩空间转换、LUT 浓度混合

4. UI 交互模块：图片预览、Cube 上传、浓度滑块、模式切换、导出下载

5. 画布输出模块：预览降采样渲染、原图分辨率高清导出

### 3\. 技术选型（最终方案）

- 核心渲染：**WebGL2（GPU 并行计算）**

- 放弃 Canvas2D CPU 方案：大尺寸相机图片卡顿、主线程阻塞

- 关键技术：GPU 硬件 3D 纹理三线性插值（杜绝色彩断层）

## 四、双渲染管线核心设计（核心功能亮点）

为同时兼容日常使用、专业调色，内置两套可切换渲染模式

### 模式 1：PS 兼容模式（简易管线）

#### 逻辑（和 Photoshop 颜色查找层 1:1 一致）

`sRGB原图像素 → 直接3D-LUT查表 → 浓度混合 → 输出sRGB`

#### 特点

1. 无任何伽马转换

2. 完全复刻 PS 原生效果

3. 性能开销最低

4. 会保留 sRGB 套 709\-LUT 的原生灰阶偏移（符合大众使用习惯）

### 模式 2：严谨专业管线（对齐 DaVinci Resolve）

#### 标准色彩链路

`sRGB原图 → sRGB伽马转Rec.709 → 3D-LUT三线性采样 → Rec.709伽马转回sRGB → LUT浓度混合 → 输出`

#### 特点

1. 彻底修复伽马不匹配偏移

2. 调色效果和专业影视软件完全一致

3. 仅增加少量 GPU 浮点运算，无纹理采样开销

### 4\. LUT 浓度调节核心公式

```Plain Text
输出颜色 = 原图RGB × (1-浓度) + LUT映射RGB × 浓度
```

- 浓度范围：0\~1

- 0 = 纯原图，1=100% LUT 效果，中间值平滑淡化

## 五、性能损耗专业评估

### 1\. 性能对比

- 简易 PS 模式：6000×4000 相机图 8\~15ms

- 严谨专业模式：6000×4000 相机图 12\~22ms

### 2\. 核心结论

1. 严谨管线仅增加**20%\~30% 着色器算术运算**，无昂贵纹理操作

2. 肉眼完全感知不到卡顿，实时滑块拖动流畅

3. 性能瓶颈不在色彩计算，仅在浏览器 JPG/PNG 编码导出

### 3\. 流畅度优化策略

1. 预览画布：自动降采样，保证交互丝滑

2. 导出功能：使用**原始图片全分辨率**渲染，兼顾预览体验和导出画质

3. 兼容降级：检测 WebGL2 环境，不支持则提示用户，不降级低效 CPU 严谨管线

## 八、关键误区归档（开发避坑）
