## 一、核心基础色彩科学原理

### 1\. sRGB 与 Rec\.709 核心异同

#### 相同点

- 色域范围完全一致

- 白点均为 D65

- 原色坐标无差异

#### 唯一核心差异

**伽马传递函数（TRC 曲线）不同**

1. Rec\.709：广播电视标准，分段曲线，专为**暗室观看电视、视频制作链路**设计

2. sRGB：互联网 / 显示器标准，分段曲线，专为**明亮室内电脑屏幕观看**设计

### 2\. 行业核心现状（历史底层原因）

1. 两套标准分属不同行业、不同年代：Rec\.709（广电 1990）、sRGB（互联网 1996）

2. 无统一的根本原因：观看环境、硬件生态、行业标准体系、海量存量素材兼容锁死

3. 视频行业默认 Rec\.709，图片行业默认 sRGB，生态割裂不可替代

### 3\. 跨空间套用 LUT 的核心问题

所有网络影视 Cube LUT，**均基于 Rec\.709 伽马制作**
直接给 sRGB 图片套用 Rec\.709 LUT：

- 色域无错误

- **灰阶、暗部、中间调会系统性偏移**（发灰、黑位异常、肤色偏移）

- 重风格 LUT 肉眼不易察觉，轻调色 LUT 偏差非常明显

## 四、双渲染管线核心设计

默认渲染 = **sRGB 直查**（Photoshop「颜色查找」行为，适合多数风格化配方）；**Rec.709 还原**作为可切换模式，用于真 Rec.709 视频信号输入的配方。

### 模式 1：Rec.709 还原

针对「**sRGB 图片 + 真 Rec.709 视频信号输入的 LUT**」（影视风格 LUT 等），等价达芬奇 `dlog → Rec.709 → 套 LUT` 对同一画面的结果。

#### 标准色彩链路

`sRGB显示值 → sRGB逆TRC → 线性光 → E'=L^(1/2.4)（Rec.709 显示信号）→ 3D-LUT 三线性采样 → L=E'^2.4 → 线性光 → sRGB正TRC → 浓度混合 → 输出`

#### 关键点

1. sRGB 与 Rec.709 **同色域、同白点，只差传递函数**，互转无需色域矩阵，只做幂律（显示信号语义）。
2. Rec.709 段用 **BT.1886 参考显示信号（纯幂律 γ=2.4）**，对齐达芬奇默认时间线「Rec.709 Gamma 2.4」。γ 常量 `REC709_DISPLAY_GAMMA`（`lutRenderer.ts` 顶部）；若达芬奇项目按 Gamma 2.2 处理，把该常量改为 2.2 即可。
3. **不要**用 BT.709 摄像机 OETF 分段公式（0.018/4.5/1.099·^0.45）：那是捕获端编码（scene\-referred），不是显示图互转所用（早期实现的错误，已修正）。
4. 修复了 sRGB 直接套 709\-LUT 造成的灰阶/黑位系统性偏移。

### 模式 2（默认）：sRGB 直查（Photoshop「颜色查找」）

#### 链路

`sRGB原图像素 → 直接3D-LUT查表 → 浓度混合 → 输出sRGB`

#### 特点

1. 无任何伽马转换，1:1 复刻 Photoshop 颜色查找层行为
2. 保留 sRGB 套 709\-LUT 的"原生偏移"——供 PS / 手机生态配方对照
3. 默认渲染路径

### 4\. LUT 浓度调节核心公式

```Plain Text
输出颜色 = 原图RGB × (1-浓度) + LUT映射RGB × 浓度
```

- 浓度范围：0\~1

- 0 = 纯原图，1=100% LUT 效果，中间值平滑淡化
