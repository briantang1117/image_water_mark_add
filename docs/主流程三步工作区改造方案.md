# 主流程三步工作区改造方案(定稿待实施)

> 状态:**已实施(2026-09-04)**。本文记录全部已确认决策;实施按 §9 任务清单拆分,全部完成。
> 基线:main @ `0139c46`(默认 sRGB 直查)。实施合入提交见 git log。

## 1. 背景与动机

当前主界面是"混排":导出控件放在顶部工具栏,和水印/LUT 混在一起;底部只有「💧 水印 / 🎨 LUT」两个功能标签,心智是"功能"而非"流程"。

**目标**:底部按「调色 → 水印 → 导出」的自然流程组织三个并列栏目,把导出独立成第三栏;顶部彻底腾空,布局稳定为上下各半,更顺手、更接近达芬奇底部操作栏的心智。

## 2. 已确认的形态(用户决策)

1. **底部三个并列栏目,自由切换(非向导)**:① 调色 ② 水印 ③ 导出。
2. **图片显示不随栏目变化**:预览始终显示**当前图片的最终合成图**(调色 + 水印都生效)。
3. **整体结构沿用现状**——栏目标题行 + 下面**只有一块内容**、点标题即整体替换内容(和现在的 Tab 一样),只是标签由 2 个变 3 个并重排为 调色→水印→导出。
4. **添加照片移到缩略图小列表末尾**:在最后一张图后放一个「+」按钮(Web 文件选择 / 原生 `pickImage`),行为为**追加**。
5. **缩略图列表最多 9 张**,「+」跟随在末尾。
6. **顶部整块移除**:标题栏 + 顶部工具栏全部去掉(含「共 N 张」计数),顶部无任何内容。
7. **「清空列表」一键清空彻底移除**,无替代入口;仅保留每张缩略图自带的删除。
8. **LUT 默认浓度 = 50%**(新建图片初始 + LUT「重置」均回到 50)。
9. **导出栏 = 仅现有配置**:格式 JPG/PNG、JPG 质量、单张下载 / 全部下载(ZIP)。不新增导出选项。
10. **预览区原图/效果图切换按钮维持现状**(预览区)。
11. **布局:屏幕上下各 50% 固定**;上半 = 预览区(图片尺寸恒定,不随切换变化)+ 缩略图条;下半 = 三步工作区,标签行固定、内容区在该 50% 内 **auto 滚动**(为将来配置变多预留)。
12. **缩略图最多 9 张为硬上限**:满 9 张后不可再加(「+」禁用或点击提示「最多 9 张」)。
13. **EXIF 信息也显示在上 50%**;显示仅保留 **品牌+型号、时间、GPS**,去掉镜头/焦段/光圈/快门/ISO/软件等——**只是显示裁剪,导出时 EXIF 回写仍为全量**,不受影响。
14. **预览无图空态**:上区提示「上传图片」。
15. **标签行沿用现有按钮样式,仅文字**(不加编号/图标)。

## 5. 布局设计说明与实施注意

**对"上下各 50%、上区固定"方案的评价(同意方向,几点落实建议):**
1. **预览固定收益明确**:切栏、加/删图时大图不再跳动,导出预览即最终效果,心智简单。
2. 上下按**视口 50%/50%**(用 `100dvh` 计算),而不是嵌套容器比例,避免双重滚动条。
3. 上区大图用 `object-fit: contain` 在固定区域内缩放,极端横/竖图以留白处理;**预览画布本身仍按当前图原始像素渲染**,只是展示容器固定——显示清晰度不受影响。
4. 下半:标签行固定(不随内容滚走),**仅内容区**在 50% 内 auto 滚动;导出栏当前内容较少,内容顶对齐即可,为将来配置变多留出滚动空间。
5. 适配窄屏/移动端:safe-area、`100dvh`;若视口很矮(如 <560px),可允许下区略小于 50% 或压缩标签行,避免两半都不可用。

**其它实施注意:**
1. 预览与导出一致:渲染仍走 `PreviewPanel` + `exportWithLut`,共用同一 `LutRenderer`;布局改动不动渲染逻辑。
2. 状态归属不变:LUT/水印仍 per-image(`lutId/lutIntensity/lutMode/wmKey/...`),换栏不丢。
3. Guardrails 不回退:WebGL2 缺失的置灰/横幅、带 LUT 导出报错(禁止静默降级)。
